このデモは何か

現行「あおぞら予ろシク」の項目・操作は一切変えず、情報設計・状態の可視化・入力の構造化だけを刷新したクリック可能な試作です。

1

施設（管理者）

申請の承認・取消・カレンダー・工場/基本情報・受付計量・ダッシュボード・チャット（全16画面）

2

運搬業者（予約者）

スマホアプリ（PWA）。空き枠の確認→申請→マイ予約→受付QR、事務局チャット（全7画面）

3

双方向の通知

業者が申請→施設に通知＆受付チャイム／施設が承認→業者スマホに通知。アプリを閉じても届く

TEST ①

施設（管理者）を見る — PC

  1. PCで aozora-home.html を開く（左メニューで全画面に移動）
  2. 申請一覧：承認待ちを“処理キュー”で。行の「承認」「編集」
  3. ダッシュボード：受入枠の混雑・空き枠の推奨・集計
  4. カレンダー：各枠の受入残をゲージ表示（満枠が一目）
  5. 計量・受付：2回計量で正味を自動計算
  6. チャット：運搬業者とのやりとり

見どころ

「機能はそのまま、見やすさだけ」を確認。現行の横長テーブルが“処理キュー”に、受入残が“ゲージ”に変わっています。

TEST ②

運搬業者アプリ — スマホで“アプリ化”

  1. スマホで右のQRを読む
  2. iPhone（Safari）：共有ボタン → 「ホーム画面に追加」
  3. Android（Chrome）：メニュー(︙) → 「アプリをインストール」/「ホーム画面に追加」
  4. ホーム画面の アイコンから起動 → 予約カレンダー→申請→マイ予約→受付QR
iPhoneは「Safariでホーム画面に追加したアプリ」でのみ通知が有効（iOS仕様）。必ずインストールしてから通知ON。AndroidはChromeで許可するだけで通知が使えます。
スマホで読み取り → 運搬業者アプリ
TEST ③

  4. PCの管理画面で 承認 すると、スマホに「予約が承認されました」が届く（アプリを閉じていてもOK）

TEST ④

双方向＋受付チャイム（事務所デスク向け）

  1. PCのChromeで 申請一覧 を開き、画面を一度クリック（音の許可）
  2. スマホ（運搬業者アプリ）で 申請 または チャット送信
  3. → PCで 「ポーン」と受付チャイムが鳴り、一覧が更新
  4. PCで 承認 → スマホに通知が返る（双方向）
受付チャイムはOSの通知設定に関係なく確実に鳴ります（事務所は管理画面を開きっぱなしの運用を想定）。最初の1クリックだけ必須です。
NOTES

ご確認・前提

  1. 本番のプッシュ通知・インストールには独自ドメインのHTTPS（SSL）が必要です
  2. iPhoneの通知はSafariで「ホーム画面に追加」したアプリのみ（iOS 16.4以降）。Androidは Chrome でそのまま可
  3. Windowsの通知は Chrome / Edge で標準対応（アドレスバーの⊞でインストールすればアプリ通知に）。出ないときは Windows設定→システム→通知 を許可＋集中モード(フォーカスアシスト)をオフ
  4. Macの通知は Chrome 推奨。macOSシステム設定→通知で Chrome を許可（事務所運用は「受付チャイム」が確実）
  5. デモはクリック可能な試作（保存・送信は擬似）。データは匿名サンプル
  6. 計量器(スケール)連携・電子マニフェスト(JWNET)・写真AI等は次フェーズの個別実装
