# あおぞら予ろシク — リデザイン提案（デモ）

産廃搬入予約システム「あおぞら予ろシク」のUIリデザイン提案。**現行機能は増減せず**、情報設計・状態の可視化・入力の構造化のみを刷新したクリック可能プロトタイプです。

- **施設（管理者）**：デスクトップ向け管理コンソール（デスクトップPWA・プッシュ通知）
- **運搬業者（予約者）**：スマホアプリ（PWA・オフライン・プッシュ通知・チャット）
- **Before / After**：`compare.html`

> デモデータはすべて匿名のサンプルです（実在の社名・担当者名・認証情報は含みません）。

## 入口
- `index.html` … 画面ツアー
- `aozora-home.html` … 管理者
- `hauler-home.html` … 運搬業者アプリ
- `compare.html` … Before/After ＋ 概算見積

## 通しデモ（2画面連動）
ウィンドウを2つ開く → 片方 `aozora-apply.html`（管理者）／もう片方 `hauler-add.html`（業者）。
業者が申請すると管理者の一覧へ即着信＋通知、管理者が承認すると業者へ通知が返ります（同一オリジンのタブ連携。本番は Web Push に置換）。

## 技術
- 依存ゼロの静的HTML＋独自CSSデザインシステム
- PWA：`manifest`（管理／業者の2種）＋ Service Worker（オフライン）＋ Web Push（通知）
- ローカル確認：`python3 -m http.server 8765`

## メモ
- 本番のプッシュ通知・インストールには独自ドメインのHTTPSが必要です。
- 配車管理システムは別システム（別リポジトリ）です。
